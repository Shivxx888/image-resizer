Frequently asked questions

Which formats are supported?

JPG/JPEG, PNG and WebP are supported for the current browser-based tools.

Does changing DPI add detail?

No. DPI changes print-size metadata or calculations; it does not create new image detail.

Can I use these tools privately?

Yes. Implemented image processing occurs locally using JavaScript and Canvas. Future tools that need a library will be clearly marked.
